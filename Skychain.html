PROJECT OVERVIEW

From booking to verification.

SkyChain follows a complete digital ticket journey, beginning with account creation and flight booking, then securing the issued ticket through OTP, payment, hashing and blockchain verification.

Flight Booking Search flights and complete the booking process.
Secure Verification OTP authentication and hash-based verification.
Blockchain Integrity Ticket snapshots and hashes are stored securely.
Role-Based Access Separate user, airline and administrator workflows.

The complete ticket journey.

A step-by-step look at how a user interacts with SkyChain from entering the platform to receiving a secured electronic ticket.

01

STARTING POINT

Home

The main landing page introduces SkyChain and guides users toward the flight booking experience.

04

AIRLINES PANEL

Managing the next step.

Airline users handle booking requests, ticket changes and flight management after receiving requests from passengers.

Airline Management Three dedicated workflows keep airline operations separate from the passenger experience.
01 / AIRLINE WORKFLOW

All Tickets

Airlines can review the tickets and booking information handled by the system.

02 / FLIGHT MANAGEMENT

Add New Flight

Airlines can add new flight routes and make them available to users through the booking system.

03 / REQUEST MANAGEMENT

Ticket Requests

Airlines review edit requests submitted by users and decide whether the requested change should be accepted.

User Request → Airline Review → Approve / Reject → Database Update

Security behind the ticket.

01

Ticket data snapshot created.

02

Hash Generation

Ticket hash generated.

03

Smart Contract

Hash and data stored on-chain.

04

Immutable Record

05

Verification

Admin compares database and blockchain hashes.

CRITICAL SECURITY

Admin Verification.

The administrator verifies ticket integrity by comparing the database hash with the hash stored on the blockchain.

ADMIN ONLY

Verify Ticket Integrity

A dedicated verification workflow allows the administrator to detect unauthorized ticket modifications.

✓
VERIFICATION RESULT

MATCH

Database hash matches the blockchain hash. No unauthorized modification detected.

×
SECURITY ALERT

MISMATCH

Hash values differ. Unauthorized modification has been detected.

VALID RECORD

Hash Match

The original ticket data remains consistent with the blockchain record.

SECURITY WARNING

Hash Mismatch

The database and blockchain values no longer match, indicating possible unauthorized modification.
